# Velocity Motors UI

A modern, responsive UI for a concept electric car company website built with HTML, TailwindCSS, jQuery, and Slick carousel.

---

## 📌 Project Description

Velocity Motors is a static UI template showcasing:

- Full-screen hero slider
- Vehicle models section with interactive cards
- Gallery carousel
- Test drive booking form with validation
- Responsive navigation with mobile toggle and dropdowns

It uses semantic HTML5 for accessibility and TailwindCSS for responsive design.

---

## 🛠 Technologies Used

- HTML5 (semantic elements)
- CSS3 / TailwindCSS
- JavaScript / jQuery
- Slick Carousel
- Font Awesome
- Google Fonts (Montserrat)
